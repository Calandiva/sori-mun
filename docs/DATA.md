# 자료

사전은 세 갈래 공개 자료를 합쳐 만든다. 원본은 저장소에 넣지 않는다
(`tools/fetch_data.py` 로 언제든 되받는다).

## 1. 표제어와 품사 — mecab-ko-dic

- 출처: <https://github.com/lindera/mecab-ko-dic> (bitbucket 원본의 미러)
- 라이선스: Apache-2.0
- 쓰는 것: 27개 품사 CSV → **표제어 244,352개**

`J.csv` 가 조사를 **기능별로** 갈라 놓은 것이 이 프로젝트에 결정적이다.
같은 `이` 라도 주격 `JKS`, 보격 `JKC`, 관형격 `JKG`, 부사격 `JKB`,
보조사 `JX` 가 각각 별개 항목이다. 덕분에 "실제 역할을 구분한 뒤 해석"
하라는 요구가 사전 층에서 바로 풀린다.

빼는 것: `Person`, `Place`, `Wikipedia`, `Hanja`, `Foreign`, `Group`,
`Inflect`. 표제어가 아니라 개체명 목록이거나 활용형 표라서다.

CSV 4번째 칸의 **비용(cost)** 은 말뭉치 통계에서 나온 값으로 낮을수록
흔하다. 말뭉치 빈도가 없는 표제어의 대체 빈도로 쓴다.

## 2. 사용 빈도 — FrequencyWords

- 출처: <https://github.com/hermitdave/FrequencyWords> (`2018/ko/ko_full.txt`)
- 바탕: OpenSubtitles 말뭉치
- 라이선스: CC-BY-SA 4.0
- 쓰는 것: 어절 688,129개 → **형태소 71,474종의 빈도**

원본은 `내가 39801` 처럼 어절 단위다. 이 상태로는 `내`(대명사)와
`가`(주격조사)의 빈도를 알 수 없다. 그래서 각 어절을 kiwi 로 쪼갠 뒤
그 어절의 출현수를 구성 형태소 모두에 더한다.

## 3. 감정 극성 — KNU 한국어 감성사전

- 출처: <https://github.com/park1200656/KnuSentiLex>
- 만든 곳: 군산대학교
- 쓰는 것: 표제어 14,854개 → **형태소 2,408개의 극성**

원본 표제어는 `가치있는`, `눈물을 흘리다` 처럼 구(句)나 활용형이 섞여
있어 형태소 사전과 바로 맞물리지 않는다. 쪼갠 뒤 내용 형태소들에 극성을
나눠 싣고 모아서 평균낸다. 짧은 표제어일수록 직접 증거이므로 무겁게
싣는다.

### 그냥 평균내면 안 되는 이유

KNU 는 부정 쪽으로 크게 치우쳐 있다(부정 9,829 : 긍정 4,871, 평균 −0.48).
그대로 두면 `하`, `사람`, `일` 처럼 긍·부정 양쪽 표제어에 두루 나오는
형태소가 그 편향을 물려받아 −1 이 되어 버린다. 실제로 처음 돌렸을 때
`하/VV` 가 무게 125로 −1 을 받았다.

두 가지로 막는다.

- **중심화** — 전체 평균 극성을 빼서 편향을 없앤다. 널리 퍼진 형태소는
  0 근처로 모이고 한쪽에 쏠린 것만 극성이 남는다.
- **일관성** — 표의 방향이 갈리면(같은 부호 비율 < 0.62) 극성을 주지 않는다.

이것으로 205개가 기각되고, `하`·`사람`·`일`·`되`·`모양` 이 중립으로
돌아왔다.

### 손질 층

`data/sentiment_overrides.tsv` 가 마지막에 덮어쓴다. 통계가 흔들리는
고빈도 형태소를 중립으로 눌러 두고(`있`, `속`, `조금` 등), 감정이
분명한데 통계가 놓칠 수 있는 것을 못박는다(`사랑` +2, `절망` −2 등).
손으로 넣은 값은 사전에서 출처 `손질` 로 남는다.

## 형태소 분석기 — kiwipiepy

- 출처: <https://github.com/bab2min/kiwipiepy>
- 라이선스: LGPL-2.1
- 쓰는 곳: 빈도 재집계, 감성사전 정렬, 그리고 실행 중 문장 분석

세종 품사 체계를 쓰므로 mecab-ko-dic 과 열쇠가 그대로 맞물린다.
불규칙 표시(`VA-I`, `VV-R`)만 떼어 내면 된다.

사전을 만드는 데에도, 문장을 옮기는 데에도 kiwi 가 필요하다.
사전이 이미 만들어져 있으면 `사전`·`찾기`·`규칙` 명령은 kiwi 없이도
돈다.

## 다시 만들기

```bash
python tools/fetch_data.py        # 원본 내려받기 (~28MB)
python tools/build_lexicon.py     # 표제어 244,352
python tools/build_frequency.py   # 형태소 빈도 71,474  (~10초)
python tools/build_sentiment.py   # 극성 2,408
python tools/build_dictionary.py  # 사전 286,068
python tools/verify.py            # 규칙 준수 확인
```

같은 원본에서는 언제나 같은 사전이 나온다. 무작위가 끼어드는 곳이 없다.
