# 변환 규칙

한국어 문장을 음악으로 옮기는 규칙 전체.
실행해서 보려면 `python -m sorimun 규칙`.

---

## 0. 네 단계

```
한국어 입력
   ↓  형태소 분석 (kiwi)
형태소 + 품사
   ↓  어절 묶기 · 문장 성분 판별
주어 / 목적어 / 서술어 / 보어 / 관형어 / 부사어 / 독립어
   ↓  성분별 규칙 매핑
음높이 · 화성 · 길이 · 쉼표
   ↓
음악 표출  (MIDI · WAV · MusicXML)
```

낱말은 사전에서 곧바로 꺼내 쓰지 않는다. **문장에서 무슨 자리를 맡는지
먼저 가린 뒤에** 해석한다. 같은 '밤' 이라도 `밤이 왔다` 의 밤(주어)과
`밤을 새웠다` 의 밤(목적어)은 다른 높이로 울린다.

---

## 1. 음역 — 2옥타브

모든 소리는 예외 없이 **C3(MIDI 48) ~ C5(MIDI 72)** 안에 있다. 정확히
2옥타브다.

| 값 | 뜻 |
|---|---|
| `LOWEST` 48 / `HIGHEST` 72 | 절대 음역. 어기면 즉시 실패한다 |
| `MAX_CHORD_SPAN` 19 | 화음 하나가 벌릴 수 있는 최대 폭 |
| `MAX_PHRASE_AMBITUS` 21 | 프레이즈 하나가 벌릴 수 있는 최대 폭 |

프레이즈 폭이 24보다 작으므로, 어떤 프레이즈든 2옥타브 안에 놓을 자리가
반드시 남는다. 그래서 음역 준수가 *증명*된다 — 소리를 만든 뒤 잘라내는
것이 아니다. 코드에서는 `pitch.assert_in_range()` 가 조용한 보정 대신
예외를 던진다.

---

## 2. 프레이즈 — 낱말의 지문

사전이 낱말에 주는 것은 **정체성**뿐이다.

```
프레이즈 = [화음, 화음, …]        (화음 1~3개)
화음     = (음정 구조, 근음 위치, 음가, 뒤따르는 쉼표)
```

**절대 음높이는 담지 않는다.** 담는 것은 음정 관계, 리듬, 쉼표뿐이다.
절대 높이는 문장 성분이 정한다(4장). 이동은 통째 조옮김이므로
`사랑이` 의 사랑과 `사랑을` 의 사랑은 높이만 다르고 같은 모티프로
들린다.

화음은 요구사항대로 **언제나 2음 또는 3음**이다(조사·어미의 홑음 제외).

## 3. 두 축

### 3.1 협화도 축 ← 사용 빈도

말뭉치 빈도로 순위를 매기고, 순위를 6등급으로 나눈다. 지프 분포에 맞춰
대수적으로 벌린다.

| 등급 | 순위 | 뜻 | 항목 수 |
|---|---|---|---|
| 0 | ~300 | 아주 흔함 | 204 |
| 1 | ~1,500 | 흔함 | 1,054 |
| 2 | ~6,000 | 보통 | 4,288 |
| 3 | ~25,000 | 드묾 | 18,545 |
| 4 | ~100,000 | 아주 드묾 | 72,521 |
| 5 | 그 밖 | 희귀·미등재 | 184,230 |

등급이 곧 **화음 어휘**를 정한다. 2음·3음 보이싱 190가지를 남김없이
만들고, 각각의 불협화도를 음정류별 거칠기의 평균으로 계산한 뒤,
낮은 쪽부터 6등급으로 가른다.

```
음정류별 거칠기
  0 (동음/옥타브)  0.05      4 (장3도/단6도)  0.24
  1 (단2도/장7도)  1.00      5 (완전4·5도)   0.12
  2 (장2도/단7도)  0.62      6 (삼전음)      0.78
  3 (단3도/장6도)  0.28
좁게 붙으면 ×1.15, 옥타브 너머로 벌리면 ×0.75
```

흔한 낱말은 완전5도·옥타브처럼 순한 소리를, 드문 낱말은 반음 뭉치나
삼전음처럼 난해한 소리를 받는다.

**길이도 빈도를 따른다.** 프레이즈 스트림은 짧은 것부터 낳으므로,
흔한 낱말일수록 화음 개수가 적다. 상위 3,241개만 1화음 음형을 쓴다.

### 3.2 장·단 축 ← 감정 극성

| 극성 | 성질 | 화음 |
|---|---|---|
| +1, +2 | 장(major) | 장3도 관계를 품은 화음 |
| −1, −2 | 단(minor) | 단3도 관계를 품은 화음 |
| 0 | 중성(neutral) | 3도가 없는 화음 — 완전5도·4도쌓기·2도 계열 |

성질 판별은 전위(자리바꿈)를 같은 성질로 본다. `(0,4,7)` 장3화음과
그 전위 `(0,3,8)`, `(0,5,9)` 는 모두 장(長)이다. 증3화음 `(0,4,8)` 은
대칭이라 어느 쪽도 아니므로 중성이다.

**두 축은 직교한다.** 등급은 성질 *안에서* 상대적으로 매긴다. 절대
불협화도로 자르면 "긍정 + 최빈어" 칸이 영원히 빈다 — 장3화음은 구조적으로
완전5도만큼 협화로울 수 없기 때문이다. 성질별로 나누면
"긍정적이지만 낯설다"(장·5등급) 같은 자리가 제대로 소리 난다.

극성의 세기(|1| 대 |2|)는 화음이 아니라 **세기(velocity)** 에 실린다.
극성이 셀수록 또렷하게 울린다.

## 4. 문장 성분 ← 음역 · 음가 · 세기

여기서 절대 높이가 정해진다.

| 성분 | 목표 최저음 | 음가 | 세기 | 성격 |
|---|---|---|---|---|
| 독립어 | G4 (67) | ×1 | 92 | 가장 높이, 앞뒤로 긴 쉼표를 두르고 홀로 |
| 관형어 | E4 (64) | ×1/2 | 62 | 높고 짧게, 뒤 체언에 곧바로 붙는다 |
| 목적어 | C4 (60) | ×1 | 80 | 중고음역, 대상을 밝게 내건다 |
| 보어 | A3 (57) | ×1 | 78 | 중음역, 주어 곁에 선다 |
| 주어 | G3 (55) | ×1 | 82 | 중저음역, 문장을 떠받친다 |
| 부사어 | E3 (52) | ×3/4 | 70 | 낮고 짧게, 색을 입힌다 |
| 서술어 | C3 (48) | ×2 | 88 | 가장 낮고 가장 길게, 문장을 내려놓는다 |

목표 높이는 프레이즈의 최저음 기준이며, 2옥타브를 벗어날 때만 눌러
맞춘다. 통째 조옮김이라 정체성은 상하지 않는다.

### 성분 판별

조사와 어미가 거의 결정한다. 한국어에서 문장 성분을 드러내는 것이
바로 그것들이기 때문이다.

| 짜임 | 성분 |
|---|---|
| 체언 + 이/가 `JKS` | 주어 |
| 체언 + 을/를 `JKO` | 목적어 |
| 체언 + 이/가 `JKC` | 보어 (되다·아니다 앞) |
| 체언 + 의 `JKG` | 관형어 |
| 체언 + 에/에서/으로 `JKB` | 부사어 |
| 체언 + 아/야/여 `JKV` | 독립어 |
| 용언 + 은/는/을 `ETM` | 관형어 |
| 용언 + 다/까/요 `EF` | 서술어 |
| 체언 + 이다 `VCP` | 서술어 |
| 관형사 `MM` | 관형어 |
| 부사 `MAG`/`MAJ` | 부사어 |
| 감탄사 `IC` | 독립어 |

조사가 없거나 보조사(은/는)뿐이면 문장 짜임으로 어림한다.

- 뒤에 진짜 주어(`JKS`)가 따로 있으면 이쪽은 주어가 아니다.
  `밥은 내가 먹었다` → 밥은 = **목적어**
- 없으면 첫 체언 어절이 주어를 맡는다.
  `나는 밥을 먹었다` → 나는 = **주어**

어림한 자리는 출력에서 `~` 로 표시한다. 완전한 구문분석이 아니라
규칙 어림임을 감추지 않는다.

## 5. 조사·어미 = 격(格)의 몸짓

조사와 어미는 뜻을 나르지 않는다. 앞말의 자리를 표시할 뿐이다.
그래서 화성이 아니라 **몸짓**으로 옮긴다. 언제나 가장 짧은
음가(16분음표)로 스치듯 지나간다.

첫 음에서 둘째 음으로 가는 음정이 곧 그 조사·어미의 정체다.

| 품사 | 이름 | 음정 | 몸짓 | 보기 |
|---|---|---|---|---|
| `JKS` | 주격조사 | +5 | 상행 완전4도 | 이 / 가 / 께서 |
| `JKC` | 보격조사 | +4 | 상행 장3도 | 이 / 가 |
| `JKG` | 관형격조사 | +1 | 상행 단2도 | 의 |
| `JKO` | 목적격조사 | −2 | 하행 장2도 | 을 / 를 |
| `JKB` | 부사격조사 | 0 | 동음 | 에 / 에서 / 으로 |
| `JKV` | 호격조사 | +12 | 상행 옥타브 | 아 / 야 / 여 |
| `JKQ` | 인용격조사 | +7 | 상행 완전5도 | 라고 / 고 |
| `JX` | 보조사 | −7 | 하행 완전5도 | 은 / 는 / 도 / 만 |
| `JC` | 접속조사 | +2 | 상행 장2도 | 와 / 과 / 하고 |
| `EP` | 선어말어미 | −1 | 하행 단2도 | 었 / 겠 / 시 |
| `EF` | 종결어미 | −5 | 하행 완전4도 | 다 / 까 / 요 |
| `EC` | 연결어미 | +3 | 상행 단3도 | 고 / 며 / 지만 |
| `ETM` | 관형형어미 | −3 | 하행 단3도 | 은 / 는 / 을 |
| `ETN` | 명사형어미 | −4 | 하행 장3도 | 음 / 기 |

표지는 앞말이 끝난 높이에서 출발한다. 그래서 낱말과 표지가 끊기지 않고
이어진다.

**같은 글자라도 기능이 다르면 다른 소리다.** `이` 하나에 주격 `JKS`,
보격 `JKC`, 관형격 `JKG`, 부사격 `JKB`, 보조사 `JX` 가 각각 사전 항목으로
들어 있고, 서로 다른 음형을 갖는다.

## 6. 문장 맺음

| 부호 | 처리 |
|---|---|
| `.` | 서술어를 가장 낮고 길게 내려놓고 긴 쉼표 |
| `?` | 마지막에 상행 장2도를 하나 덧붙여 말끝을 올린다 |
| `!` | 서술어의 세기를 +14 올리고 쉼표를 짧게 |

## 7. 겹치지 않음

> "음악으로 변환(겹치지 않아야 해)"

286,068개 항목 어느 둘도 같은 프레이즈를 갖지 않는다. 이것은 사후
검사로 얻은 성질이 아니라 **구성상 보장**된다.

### 근거 1 — 칸끼리

화음 모양 190가지를 (등급 × 성질) 18칸으로 **완전 분할**한다. 한 모양은
정확히 한 칸에만 속한다. 프레이즈는 제 칸의 모양만 쓴다. 그러므로 서로
다른 칸의 두 프레이즈는 첫 화음부터 이미 다르다.

### 근거 2 — 칸 안에서

한 칸 안에서는 결정적 스트림에서 하나씩 떼어 쓴다. 재사용이 없다.

### 근거 3 — 내용어와 문법 표지

가장 짧은 음가(16분음표)는 조사·어미 전용으로 예약했다. 내용어 음가
목록 `(4, 2, 8, 3, 6)` 에는 16분음표가 없다. 그래서 둘은 결코 같은
프레이즈가 될 수 없다.

### 근거 4 — 표지끼리

첫 음정이 곧 그 격의 정체이며, 14개 기능에 서로 다른 음정을 배정했다.

### 근거 5 — 미등재어

사전에 없는 낱말은 **화음 4개**짜리 음형을 받는다. 사전 항목은 최대
3개까지만 쓰므로 개수만으로 이미 갈린다. 모르는 말은 길고 낯설게
울린다.

`python tools/verify.py` 와 `tests/test_injectivity.py` 가 실제로
전수 확인한다.

### 솔직하게 —

프레이즈는 유일하지만 **음높이 배열**은 23,768가지다. 두 낱말이 같은
화음을 쓰되 음가나 쉼표가 다른 경우가 있다는 뜻이다. 요구사항이 든
네 가지 재료(음높이·화성·길이·쉼표)를 모두 써서 가르므로 규칙은
지켜지지만, 화음만 듣고 낱말을 되짚을 수는 없다.

특히 0등급(가장 흔한 204개 낱말)은 34가지 음높이 배열을 나눠 쓴다.
협화로운 화음 자체가 몇 개 없기 때문이다. 이것은 결함이라기보다
결과다 — 늘 쓰는 말들은 비슷하게 순한 소리를 내고, 드문 말이 도드라진다.
