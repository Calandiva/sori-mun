화음의 협화도는 낱말의 사용 빈도가, 장·단은 감정 극성이 정한다. 두 축은 직교한다. 그리고 절대 음높이는 문장 성분이 정한다.

협화도 ← 사용 빈도

문장 성분 ← 음역 · 음가 · 세기

조사 · 어미 = 격(格)의 음정 몸짓 — 언제나 16분음표

조사는 뜻을 나르지 않는다. 앞말의 자리를 표시할 뿐이다. 그래서 화성이 아니라 몸짓으로 옮긴다. 첫 음에서 둘째 음으로 가는 음정이 곧 그 격의 정체다. 같은 ‘이’ 라도 주격·보격·관형격·부사격·보조사가 각각 다른 소리를 갖는 까닭이다.

INJECTIVITY겹치지 않음

28만 항목 어느 둘도 같은 프레이즈를 갖지 않는다. 사후 검사로 얻은 성질이 아니라 구성상 보장된다.

  1. 화음 모양 190가지를 (등급 × 성질) 18칸으로 완전 분할한다. 한 모양은 정확히 한 칸에만 속한다.
  2. 프레이즈는 제 칸의 모양만 쓴다. 그러므로 다른 칸의 프레이즈와는 첫 화음부터 이미 다르다.
  3. 한 칸 안에서는 결정적 스트림에서 하나씩 떼어 쓴다. 재사용이 없다.
  4. 가장 짧은 음가(16분음표)는 조사·어미 전용이다. 내용어 음가 목록에 없으므로 둘은 갈린다.
  5. 사전에 없는 낱말은 화음 넷짜리 음형을 받는다. 사전 항목은 최대 셋이다.
$ python tools/verify.py ✓ 겹침 없음 — 286,068개 프레이즈가 모두 다르다 ✓ 음역 — 모든 항목이 C3~C5 (2옥타브) 안. 최대 폭 21반음 ✓ 갈래 분리 — 16분음표는 조사·어미 전용, 내용어에는 없다 ✓ 축 일치 — 긍정=장, 부정=단, 중립=중성 / 순위=등급

다만 정직하게 — 프레이즈는 유일하지만 음높이 배열은 23,768가지다. 두 낱말이 같은 화음을 쓰되 음가나 쉼표가 다른 경우가 있다는 뜻이다. 요구된 네 가지 재료를 모두 써서 가르므로 규칙은 지켜지지만, 화음만 듣고 낱말을 되짚을 수는 없다. 특히 0등급(가장 흔한 204개 낱말)은 34가지 배열을 나눠 쓴다 — 협화로운 화음 자체가 몇 개 없기 때문이다.
