# 소리문 (sori-mun)

### ▶ **[calandiva.github.io/sori-mun](https://calandiva.github.io/sori-mun/)** — 브라우저에서 바로 보고 들어보기

한국어 문장을 음악적 표현으로 옮긴다.

낱말을 소리에 아무렇게나 붙이지 않는다. 문장을 형태소로 풀고, 각
낱말이 **문장에서 실제로 맡은 자리**를 가린 뒤, 그 자리에 맞는
규칙으로 옮긴다. 음높이·화성·길이·쉼표 네 가지만 쓴다.

```
한국어 입력  →  문장 성분 구분  →  성분별 규칙 매핑  →  음악 표출
```

두 가지가 소리의 성질을 정한다.

- **흔한 말일수록 순한 화음, 드문 말일수록 난해한 화음** — 사용 빈도가 협화도를 정한다
- **긍정어는 장(長) 관계, 부정어는 단(短) 관계** — 감정 극성이 화음의 성질을 정한다

모든 소리는 **C3~C5, 정확히 2옥타브** 안에 있다.
사전 **286,068개 항목** 어느 둘도 같은 프레이즈를 갖지 않는다.

## 해보기

설치 없이 보려면 **[웹페이지](https://calandiva.github.io/sori-mun/)** 로.
예제 문장의 성분 분석과 악보를 보고, 그 자리에서 소리로 들을 수 있다.
낱말을 넣어 그 음형을 찾아볼 수도 있다.

직접 돌려보려면:

```bash
git clone https://github.com/Calandiva/sori-mun.git
cd sori-mun
python -m venv .venv && ./.venv/bin/pip install -e ".[analyze]"
```

문장을 옮긴다.

```bash
python -m sorimun 옮김 "아름다운 노래가 어두운 밤을 천천히 어루만졌다." --mid --wav
```

```
『아름다운 노래가 어두운 밤을 천천히 어루만졌다.』
  어절          성분     형태소
  ──────────────────────────────────────────────────────────────
  아름다운        관형어     아름답/VA 은/ETM
  노래가         주어      노래/NNG 가/JKS
  어두운         관형어     어둡/VA 은/ETM
  밤을          목적어     밤/NNG 을/JKO
  천천히         부사어     천천히/MAG
  어루만졌다       서술어     어루만지/VV 었/EP 다/EF

  형태소         품사          등급          성질        음형
  ────────────────────────────────────────────────────────────────────
  아름답/VA      형용사        1 흔함         장(긍정) +2   1음형
  은/ETM       관형형어미      표지 -3반음      하행 단3도     2음형
  노래/NNG      일반명사       1 흔함         장(긍정) +2   1음형
  가/JKS       주격조사       표지 +5반음      상행 완전4도    2음형
  어둡/VA       형용사        2 보통         단(부정) -1   1음형
  밤/NNG       일반명사       0 아주 흔함      중성         1음형
  ...
```

낱말의 음형을 찾는다.

```bash
python -m sorimun 사전 사랑
python -m sorimun 사전 은          # 은/JX, 은/ETM, 은/NNG, 은/EC …
python -m sorimun 찾기 --pos VA --polarity -2      # 부정 형용사만
python -m sorimun 규칙                             # 규칙 전체
```

`--mid`, `--wav`, `--xml` 로 각각 MIDI, WAV, MusicXML 을 낸다.
`examples/` 에 여섯 문장의 결과가 들어 있다.

## 어떻게 옮기는가

### 1 · 문장 성분을 먼저 가린다

같은 '밤' 이라도 자리가 다르면 다르게 울려야 한다. 한국어에서 그 자리를
드러내는 것은 조사와 어미다.

| 짜임 | 성분 | 소리에서 |
|---|---|---|
| 체언 + 이/가 `JKS` | 주어 | 중저음역, 문장을 떠받친다 |
| 체언 + 을/를 `JKO` | 목적어 | 중고음역, 대상을 밝게 내건다 |
| 체언 + 이/가 `JKC` | 보어 | 중음역, 주어 곁에 선다 |
| 용언 + 다/까 `EF` | 서술어 | 가장 낮고 가장 길게 |
| 용언 + 은/는 `ETM` | 관형어 | 높고 짧게, 뒤 체언에 붙는다 |
| 부사 / 체언 + 에 `JKB` | 부사어 | 낮고 짧게, 색을 입힌다 |
| 감탄사 / 체언 + 아 `JKV` | 독립어 | 가장 높이, 앞뒤로 긴 쉼표 |

조사가 없거나 보조사(은/는)뿐이면 문장 짜임으로 어림한다.
`밥은 내가 먹었다` 에서는 뒤에 진짜 주어가 있으므로 `밥은` 이 목적어다.
어림한 자리는 `~` 로 표시해 감추지 않는다.

### 2 · 정체성과 자리를 나눈다

사전이 낱말에 주는 것은 **음정 구조·리듬·쉼표**뿐이다. 절대 높이는
담지 않는다. 높이는 문장 성분이 정한다.

이 분리 덕분에 두 가지가 동시에 성립한다.

- `사랑이` 의 사랑과 `사랑을` 의 사랑은 높이만 다르고 **같은 모티프**로 들린다
- 자리를 옮기는 것이 통째 조옮김이므로 **2옥타브 준수가 증명된다**

### 3 · 조사와 어미는 격(格)의 몸짓이다

조사는 뜻을 나르지 않으므로 화성이 아니라 몸짓으로 옮긴다. 언제나
16분음표로 스치듯 지나간다. 첫 음에서 둘째 음으로 가는 음정이 곧
그 격의 정체다.

| | | | | | |
|---|---|---|---|---|---|
| 주격 이/가 | **상행 완전4도** | 목적격 을/를 | **하행 장2도** | 관형격 의 | **상행 단2도** |
| 보조사 은/는 | **하행 완전5도** | 부사격 에/에서 | **동음** | 호격 아/야 | **상행 옥타브** |
| 종결 다/까 | **하행 완전4도** | 연결 고/며 | **상행 단3도** | 관형형 은/는/을 | **하행 단3도** |

같은 글자라도 기능이 다르면 다른 소리다. `이` 하나에 주격·보격·관형격·
부사격·보조사가 각각 사전 항목으로 들어 있다.

전체 규칙은 **[docs/RULES.md](docs/RULES.md)**.

## 겹치지 않음

> "음악으로 변환(겹치지 않아야 해)"

286,068개 항목 어느 둘도 같은 프레이즈를 갖지 않는다. 사후 검사로 얻은
성질이 아니라 **구성상 보장**된다.

1. 화음 모양 190가지를 (등급 × 성질) 18칸으로 **완전 분할**한다. 한 모양은 한 칸에만 속한다.
2. 프레이즈는 제 칸의 모양만 쓰므로, 다른 칸의 프레이즈와는 첫 화음부터 다르다.
3. 한 칸 안에서는 결정적 스트림에서 하나씩 떼어 쓴다. 재사용이 없다.
4. 16분음표는 조사·어미 전용이다. 내용어 음가 목록에 없으므로 둘은 갈린다.
5. 미등재어는 화음 4개짜리 음형을 쓴다. 사전 항목은 최대 3개다.

```bash
python tools/verify.py
```

```
✓ 겹침 없음 — 286,068개 프레이즈가 모두 다르다
✓ 음역 — 모든 항목이 C3~C5 (2옥타브) 안. 최대 폭 21반음
✓ 갈래 분리 — 16분음표는 조사·어미 전용, 내용어에는 없다
✓ 축 일치 — 긍정=장, 부정=단, 중립=중성 / 순위=등급
```

**다만 정직하게** — 프레이즈는 유일하지만 *음높이 배열*은 23,768가지다.
두 낱말이 같은 화음을 쓰되 음가나 쉼표가 다른 경우가 있다. 요구된 네 가지
재료를 모두 써서 가르므로 규칙은 지켜지지만, 화음만 듣고 낱말을 되짚을
수는 없다. 특히 0등급(가장 흔한 204개)은 34가지 배열을 나눠 쓴다 —
협화로운 화음 자체가 몇 개 없기 때문이다.

## 사전

| | |
|---|---|
| 항목 | **286,068** |
| 조사·어미 | 5,226 (기능별로 갈림) |
| 극성 부여 | 2,337 |
| 자료 | mecab-ko-dic + FrequencyWords + KNU 한국어 감성사전 |

`data/dictionary.tsv.gz` 하나에 다 들어 있다. 셸에서도 바로 훑을 수 있다.

```bash
gzip -dc data/dictionary.tsv.gz | grep $'^사랑\t'
```

자료 출처와 가공 과정은 **[docs/DATA.md](docs/DATA.md)**.
다시 만들려면:

```bash
python tools/fetch_data.py && \
python tools/build_lexicon.py && \
python tools/build_frequency.py && \
python tools/build_sentiment.py && \
python tools/build_dictionary.py && \
python tools/verify.py
```

같은 원본에서는 언제나 같은 사전이 나온다. 무작위가 끼어드는 곳이 없다.

## 알아 둘 것

- 문장 성분 판별은 **규칙 어림**이다. 구문분석기가 아니다. 조사가 분명하면
  정확하고, 생략되면 문장 짜임으로 짐작한다.
- 감정 극성은 KNU 감성사전에서 왔고 형태소 2,408개에만 붙어 있다.
  나머지는 중립이며, 중립도 소리로는 한 자리를 차지한다(3도 없는 화음).
- WAV 는 결과를 바로 들어보라고 넣은 단순 가산합성이다. 제대로 들으려면
  MIDI 를 신시사이저에 넣는 편이 낫다.
- 사전을 만들거나 문장을 분석하려면 `kiwipiepy` 가 필요하다. 이미 만들어진
  사전을 훑어보는 데에는 표준 라이브러리만으로 충분하다.
