# 소리문 (sori-mun)

### ▶ **[calandiva.github.io/sori-mun](https://calandiva.github.io/sori-mun/)** — 문장을 넣으면 음악으로, 음악을 넣으면 두 말로

한국어와 영어를 **같은 소리**로 적는다. 그 소리는 어느 말의 것도 아니어서,
다시 어느 말로든 읽어 낼 수 있다.

```
영어를 넣으면            The child laughed quietly.
   ↓ 소리로
소리                     ♪ ♪ ♪ ♪ …
   ↓ 되읽으면
한국어로                 아이가 조용히 웃었다.
   ↓ 다시 소리로, 다시 영어로
                         The child laughed quietly.
```

**낱말은 2~10음의 멜로디**다. 첫 두 음(서명)이 감정(장3도/단3도/삼전음)과
익숙함(도약의 거칢 6단계)을 노래하고, 나머지 음들이 그 성질의
음계(장음계·자연단음계·온음계) 위를 거닐며 번호를 적는다. **저음의
화음은 구조**(문장 성분·갈래·경계)를 묘사한다 — 화음이면 구조, 홑음이면
이름. 부호를 나르는 것은 음높이와 화성뿐이라, 길이를 흔들어도 뜻은
그대로다.

모든 소리는 **C3~C5, 정확히 2옥타브** 안에 있다.

## 해보기

```bash
git clone https://github.com/Calandiva/sori-mun.git
cd sori-mun
python -m venv .venv && ./.venv/bin/pip install -e ".[analyze]"
```

**글을 소리로.**

```bash
python -m sorimun 옮김 "The child laughed quietly." --mid
```

**소리를 글로** — 어느 말로든. MIDI 도 되고 **소리 파일(WAV) 자체**도 된다.
내려받은 음원을 그대로 다시 넣으면 글자까지 정확히 돌아온다.

```bash
python -m sorimun 읽기 -f out/소리문.wav
```

```
out/소리문.mid 에서 화음 26개

  되찾은 것                     자리     갈래
  ────────────────────────────────────────────
  the/DT                    표지    en 전용
  아이 ↔ child                주어    개념 (두 말 다)
  웃 ↔ laugh                 서술어   개념 (두 말 다)
  었 ↔ «past»                표지    개념 (두 말 다)
  조용히 ↔ quietly             부사어   개념 (두 말 다)

  한국어   『아이가 조용히 웃었다.』
  영어    『The child laughed quietly.』
```

음이름을 손으로 넣어도 된다.

```bash
python -m sorimun 읽기 --notes "G3+D#4+F4 C3+C4 F3+G3+C4 ..." --to ko
```

그 밖에 `사전`(낱말), `개념`(두 말을 잇는 표), `규칙`(전체 규칙).

## 어떻게

### 글리프 — 낱말 하나

```
[역할 화음(저음)] ([언어·받아적기 화음]) [이름 멜로디 3~10음] [맺음 화음]
```

| 자리 | 담는 것 |
|---|---|
| **역할 화음** (저음) | 문장 성분 — 화음 모양 8가지 |
| **갈래 화음** (저음) | 언어 전용 / 받아적기. 개념이면 없다 |
| **서명 1·2** (홑음) | 성질(3도)과 등급(도약의 거칢) |
| **자릿음** (홑음 1~8) | 번호 — 그 성질의 음계 위 계단이 진법 한 자리 |
| **맺음 화음** (저음) | 글리프의 끝. 어절 경계도 말한다 |

쉼표가 아니라 **맺음 화음**이 경계를 말한다. 쉼표도 길이이기 때문이다.
흔한 낱말은 3음, 희귀한 낱말은 10음 — 지프의 법칙이 가락의 길이로 들린다.

### 소리에는 말이 담기지 않는다

두 말에 다 있는 낱말은 **개념 번호**로 적힌다. 조사·어미와 관사·어순은
그 말의 것이므로 담지 않고, 읽어 낼 때 자리를 보고 새로 붙인다.

```
소리 :  (아이/child, 주어) (웃다/laugh, 서술어) (과거) (조용히/quietly, 부사어)
```

문법도 개념이다. 한국어 `었/EP` 와 영어 `-ed` 는 같은 「과거」 개념이다.
영어 쪽은 낱말 안에 녹아 있으므로 분석할 때 갈라 세운다 —
`touched → touch + «past»`.

### 두 축

- **협화도 ← 빈도** — 흔한 낱말은 순한 화음, 드문 낱말은 난해한 화음
- **장·단 ← 감정** — 긍정은 장3도 관계, 부정은 단3도 관계, 나머지는 중성

자릿 화음도 그 낱말의 성질을 따르므로, 이름을 적는 내내 감정의 색이 이어진다.

전체 규칙은 **[docs/RULES.md](docs/RULES.md)**,
규칙 하나하나의 언어학·음악학 근거와 한계는 **[docs/THEORY.md](docs/THEORY.md)**.
`tools/verify_axes.py` 가 두 축의 조화를 상시 검증한다 — 같은 성질 안에서
등급이 오를수록 불협화도가 고르게 단조 증가하고(성질별 거칢 6등분),
네 사분면(흔함×장·흔함×단·드묾×장·드묾×단)이 실제 낱말로 차 있으며
서로 다른 화음을 받는다.

```bash
python tools/verify.py
```

```

✓ 글리프 19,008가지가 값 그대로 돌아온다
✓ 모든 소리가 C3~C5 안 (정확히 2옥타브)
✓ 길이·세기를 마구 흔든 180번 모두 같은 뜻으로 읽힌다
✓ ko 사전 286,068항목이 번호로 되찾아진다
✓ en 사전 260,000항목이 번호로 되찾아진다
✓ 개념 7,892개가 번호·한국어·영어 어느 쪽으로도 찾아진다
✓ ko 문장 30/30 이 글자까지 그대로 돌아온다
✓ en 문장 30/30 이 글자까지 그대로 돌아온다
✓ 60/60 문장이 소리 파일(WAV)을 거쳐 글자까지 그대로 돌아온다
✓ 영어→소리→한국어→소리→영어 에서 뜻의 29/30 이 살아남는다
```

**겹치지 않음은 구성상 따라 나온다.** 되읽기가 (자리·대문자·갈래·말·등급·
성질·번호·맺음)을 남김없이 되찾으므로, 서로 다른 값이 같은 소리를 가지는
일은 있을 수 없다. 그렇다면 되찾기가 두 값을 같은 것으로 답해야 하는데
그럴 수 없기 때문이다. 검사는 그 구성이 실제로 그러한지 보는 것이다.

`python -m pytest` — 시험 157개. 웹페이지에는 전체 사전 검색(546,068항목),
화음을 눌러 낱말을 짓는 안내형 입력, 그리고 문장이 해체되어 음악이 되는
전 과정을 선과 도식만으로 보여 주는 시각화 화면이 있다.

## 지키지 못하는 것

- **개념표는 7,895개, 근사가 6,245개다.** 두 말에 다 있는 낱말은 개념으로,
  한쪽에만 있는 낱말은 가장 가까운 개념으로 이어진다(어루만지다 ≈ touch).
  같은 말로는 언제나 정확한 낱말이 돌아오고, 근사는 다른 말로 읽을 때만
  쓰인다. 그래서 영어→소리→한국어→소리→영어 를 돌아도 핵심 낱말 29/30 이
  살아남는다.
- **생성은 단순하다.** 주어·서술어·목적어가 뚜렷한 문장은 잘 옮겨지지만,
  비교급·관계절·복문은 자리로 환원되면서 무너진다.
- **문장 성분 판별과 영어 품사 붙이기는 규칙 어림**이지 구문분석이 아니다.
  다만 결정적이므로 같은 문장은 언제나 같은 소리가 되고, 같은 소리는 언제나
  같은 뜻으로 돌아온다.
- **웹페이지는 적기와 되읽기를 둘 다 브라우저에서 한다.** 한국어 가르기는
  사전 앞머리 맞추기 + 활용표라 파이썬(형태소 분석기)보다 거칠고, 갈리지
  않는 어절은 글자로 받아 적는다 — 소리는 길어지지만 60/60 문장이 자체
  왕복에서 글자까지 그대로 돌아온다.
